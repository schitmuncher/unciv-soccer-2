# Unciv Soccer — EPL to L2 Mod v1.1

A full football-themed reskin of Unciv. Build your firm, conquer rival stadiums, and reach glory.

## What's New in v1.1
- **Full unit roster**: Ranged (Bottle Thrower → Pyro Specialist), Cavalry (Moped Lads → Riot Van), Siege (Turnstile Breaker → Megaphone Agitator)
- **New UnitTypes**: Cavalry and Siege added for tactical rock-paper-scissors combat
- **New Resources**: Local Talent, Foreign Investors, Craft Beer, Prawn Sandwiches, Vintage Kits
- **New Tile Improvements**: Training Camp (provides Local Talent), Hospitality Box (provides Prawn Sandwiches), Scouting Post
- **Lore-accurate Club Abilities**: Manchester City gets Oil Money (+50% gold), Liverpool gets YNWA (heal on kill), Brighton gets The Data Club (+25% science), Chelsea gets Sack the Manager (+25% Great People), etc.
- **Policy trees overhauled**: Sugar Daddy Takeover, Terrace Mentality, and Youth Academy Focus now have distinct, flavourful bonuses

## Victory Conditions
- **Domination**: Burn down every rival stadium
- **Science (Super League)**: Build all spaceship parts via Oil State Takeover and Global Franchise
- **Cultural (Legendary Status)**: Accumulate culture and wonders
